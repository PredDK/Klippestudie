# Klippestudie

Klippestudie er en videoeditor, der kører i browseren. Du skal ikke installere noget. Den er lavet til at redigere videoer til TikTok, Reels, Shorts, YouTube og andre sociale medier.

Hele programmet ligger i én fil, `index.html`. Videoerne bliver behandlet lokalt på din egen computer, så intet bliver uploadet nogen steder hen.

## Sådan bruger du den

1. Åbn `index.html` i Chrome eller Edge på en PC.
2. Upload eller træk dine videoer, billeder og din musik ind.
3. Redigér og eksportér som MP4.

Du kan også lægge den på GitHub Pages. Gå til **Settings → Pages**, og vælg branchen `main` som kilde. Så kan editoren åbnes fra et link.

## Funktioner

- **Tidslinje:** du kan trimme, dele (S), ændre rækkefølgen, ændre hastigheden og klippe start og slut til afspilningshovedet (Q og W).
- **Snap:** kanter og afspilningshovedet hænger fast i hinanden. Du kan flytte ét billede ad gangen og hoppe mellem klip-kanterne.
- **Video som lag:** du kan flytte og zoome videoen i billedet og vælge, hvilket udsnit der skal vises. Den del, der falder udenfor, vises svagt rundt om billedet.
- **Formater:** 9:16, 4:5, 1:1, 16:9, 4:3, 3:4, 2:3 og 21:9. Lærredet kan også tilpasses videoen, eller du kan vælge en brugerdefineret størrelse.
- **Tekst:** 59 Google-skrifttyper og 14 færdige stilarter. Du kan bruge kontur, skygge, glød, baggrundsboks, farveovergang og bogstavafstand.
- **Elementer:** 16 figurer, blandt andet en statuslinje, der vokser mens videoen spiller. Der er også hurtige elementer som navneskilt og abonnér-knap, 36 emoji-stickers og billeder eller logoer som overlay.
- **Animationer:** lag kan flyve ind og ud fra alle sider. Der er også pop, bounce, stomp, rotation, sløring, skrivemaskine og ord for ord, samt gentagne bevægelser som puls, svæv og vrik.
- **Effekter:** 18 effekter, fx zoom-punch, rystelse, glitch, VHS, filmkorn og lyslæk, og 6 overgange mellem klip.
- **Lyd:** du kan udskifte lydsporet og trække lyden ud af et videoklip. Der er 7 musikstile og 20 lydeffekter, som laves i browseren og er fri til brug.
- **Filtre og farver:** filtre, lysstyrke, kontrast og mætning, fade ind og ud samt sløret baggrund.
- **Eksport:** MP4 i 720p, 1080p, 1440p eller 4K.

## Genveje

| Tast | Funktion |
|---|---|
| Mellemrum | Afspil / pause |
| S | Del ved afspilningshovedet |
| Q / W | Klip start / slut til afspilningshovedet |
| ← / → | Ét billede frem eller tilbage (Shift: 1 sek) |
| ↑ / ↓ | Forrige / næste klip-kant |
| Ctrl+Z / Ctrl+Y | Fortryd / gentag |
| Ctrl+D | Dupliker |
| Delete | Slet valgt |

## Begrænsninger

- Eksporten optager videoen mens den afspilles, så den tager lige så lang tid som videoen. Fanen skal være åben og synlig imens.
- Projektet bliver ikke gemt. Eksportér, før du lukker siden.
- Den virker bedst i Chrome og Edge. Nogle iPhone-videoer i HEVC-format kan ikke åbnes i alle browsere.
